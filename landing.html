4096

Junta os números e chega ao bloco 4096!

Um puzzle simples numa grelha 4×4. Desliza os blocos, funde números iguais e soma pontos até criares o lendário bloco 4096. Funciona no browser, no desktop e no telemóvel.

Como jogar

Três passos para começares. Ganhas ao criar o bloco 4096; perdes se a grelha encher sem movimentos possíveis.

  1. Move os blocos

    Usa as ← ↑ ↓ → no teclado, ou faz swipe no telemóvel.

  2. Funde números iguais

    Quando dois blocos com o mesmo número se tocam, fundem-se num só e somas pontos.

  3. Chega ao 4096

    Cria o bloco 4096 para ganhar. Depois podes continuar para bater o teu recorde.

Funcionalidades

Pequeno, rápido e sem dependências — igual ao original, com objetivo 4096.

  • ⚡

    Sem build

    HTML + CSS + JS puro. Abre o index.html e joga, sem npm nem compilação.

  • 📱

    Swipe no telemóvel

    Suporte a setas do teclado e gestos touch. Funciona no desktop e no mobile.

  • 🏆

    Best score local

    O melhor resultado fica guardado no browser com localStorage. Sem conta, sem servidor.

  • ♾️

    Continuar após vitória

    Ao chegar ao 4096 podes escolher continuar para pontuações ainda maiores.

Como executar localmente: abre index.html com duplo clique (file://), ou serve a pasta: python -m http.server 8000  # depois abre http://localhost:8000/landing.html
